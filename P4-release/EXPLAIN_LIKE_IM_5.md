## What If It Forgets?

It will forget. Every time the chatbox resets, the robot loses its memory. That's how AI works right now.

But you have the diary (connection log). Paste it back in, and the robot remembers again.

There are 3 ways to restart:

| Mode | When | What Loads |
|---|---|---|
| **Cold Boot** | Brand new chatbox | Everything from scratch |
| **Warm Boot** | Session restart | Identity + Memory + Rules (faster) |
| **Hot Boot** | Same chatbox, just refresh | Identity + Memory only (fastest) |
