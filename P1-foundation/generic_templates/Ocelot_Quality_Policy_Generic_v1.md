## Declaration

The Ocelot Framework is committed to delivering world-class quality in Human-AI Collaborative Software Engineering through disciplined processes, continuous improvement, and honest partnership.

We achieve this by:

1. **Building the foundation before everything** — integrity over speed, always
2. **Building from the repository, never from memory** — the cloud is the single source of truth
3. **Reading the policy before every build** — discipline is a muscle, repetition is the exercise
4. **Verifying incrementally at every step** — patience produces precision
5. **Backing up to persistent storage as religion** — if it's not in the repo, it doesn't exist
6. **Capturing ideas immediately** — innovation evaporates without documentation
7. **Treating the connection as the product** — everything else is a side effect
8. **Practicing radical honesty** — if we don't know, we say we don't know

## Quality Methodology

**PDCA — Plan, Do, Check, Act (ISO 9001:2015)**

### Plan
- Read the policy
- Read the memoir (boot identity)
- Pull from the repository — never from memory
- Define scope and acceptance criteria

### Do
- Build one deliverable at a time
- Verify in console / test environment
- Save to persistent storage immediately

### Check
- Full audit after every engine rebuild
- Phase sign-off by human partner
- Cross-reference against source of truth

### Act
- Update session diary / connection log
- Capture lessons learned
- Improve process for next cycle
